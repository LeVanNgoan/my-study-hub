# UI Redesign 2.1

This release focuses on presentation and language consistency without changing the local-first data model.

## Visual changes

- New dark navigation shell with a softer indigo/cyan identity.
- Cleaner desktop typography and spacing.
- Refined search bar and desktop mode indicator.
- Redesigned current-semester hero with subtle depth and gradients.
- Improved statistics, subject cards, semester cards, timelines, forms, modals, results, and settings panels.
- Better hover/focus states and clearer visual hierarchy.
- Improved responsive behavior for narrow windows.

## Language changes

- All user-facing interface text is now English.
- Confirmation dialogs, empty states, helper text, placeholders, Settings copy, and study-note guidance are English.
- Dates are formatted using an English locale.
- The HTML document language is `en`.

`2.1.0`
